# 🧠 Quiz Game

An interactive and responsive Quiz Game built with modern frontend technologies. This project engages users through a series of questions, tracks progress, and displays results — all while demonstrating core frontend development skills such as component structure, state management, UI updates, and dynamic rendering.

---

## 🚀 Features

* Interactive quiz interface
* Multiple-choice questions
* Real-time answer selection
* Score tracking system
* Responsive design (mobile and desktop friendly)
* Clean and user-friendly experience
* Dynamic rendering of questions and results

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6+)
* React

## ⚙️ Getting Started

### Prerequisites

* Node.js installed
* npm or yarn

### Installation

1. Clone the repository:

```bash
git clone https://github.com/DamiiDev/Quiz-Game.git
```

2. Navigate into the project directory:

```bash
cd Quiz-Game
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm start
```

---

## 💡 How It Works

* Displays a series of quiz questions
* Users select answers from multiple-choice options
* User selections are recorded and UI updates dynamically
* Final score/result displayed at the end
* React state manages question index, selected answers, and score
