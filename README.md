# 🧠 Quiz Game

An interactive and responsive quiz game built with modern frontend technologies. This project is designed to test users’ knowledge through a series of questions while demonstrating core frontend development concepts such as state management, user interaction, and dynamic UI rendering.

---

## 🚀 Features

- Interactive quiz interface
- Multiple-choice questions
- Real-time answer selection and feedback
- Score tracking system
- Responsive design (mobile and desktop friendly)
- Dynamic rendering of questions and options
- Clean and intuitive user experience

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
